# TestForge exports

`recording.json` is the source of truth. `playwright_test.py` and `playwright_test.js` are sequential Playwright replays. Download ALL resource files together. Python needs playwright; JavaScript/TypeScript use the included package.json (npm install). The TypeScript project runs with npm test and uses one worker, no retries, no video and failure-only screenshots. Jenkinsfile invokes Python (set TF_VAR_<name> environment variables for placeholders). The Gherkin feature needs project-specific step definitions. Azure DevOps, Jira and TestComplete CSV/XLSX files are import templates that require mapping to the target instance; they are not native proprietary recordings. Re-import steps.json for a lossless canonical round trip; the Azure DevOps, Jira and TestComplete tables round-trip too, because the label carries the repeat marker (" ×N") and the Selector column carries the recorded locator. Arbitrary generated runtime code is not executed by the importer. Screenshots are PNG. Video, when enabled, is WebM, not PNG.
