# Windows desktop replay

Sequential only. `python desktop_test.py` uses the deterministic simulated UIA tree unless `TF_WINDOWS_AGENT_URL` and `TF_WINDOWS_AGENT_TOKEN` name an authenticated Windows agent (FlaUI/UIA/WinAppDriver worker). `DesktopRunner.cs` is the equivalent C# agent client for .NET shops. No credentials are stored in this bundle.
